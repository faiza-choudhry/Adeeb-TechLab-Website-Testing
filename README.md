# Adeeb TechLab Website – Manual QA Testing

## Project Overview

This project focuses on the manual Quality Assurance (QA) testing of the **Adeeb TechLab website** to evaluate its functionality, navigation, user interface, usability, and overall user experience.

The objective was to assess the website from an end-user perspective, identify potential issues, and document observations and improvement opportunities to support better website quality.
